Project 4

Organizing The Parts On Prusa Slicer:

For my fourth project my partner and I were tasked to assemble a hand using the 3D printer and then add something to the hand. I downloaded the stl file off of e-NABLE (https://hub.e-nable.org/s/e-nable-devices/wiki/Phoenix+v2+Hand) and then transferred it to Prusa Slicer. Our first task for this project was to organize each part of the hand onto a build plate but we could not fit them all on one build plate. At first I managed to fit them all onto two build plates but I forgot that we had to scale them to 150% so that everyone could switch parts with other people and it is easier to assemble. We had to reorganize the parts in the end taking three build plates. Another issue we ran into were some of the parts for the hand, mostly the pins for the hands. It had a small surface area touching the build plate so just to be safe we added 3 layers of rafts so it stuck to the build plate better. We also added organic supports only on the build plate to support the fingers. When it was finished there wasn’t any trouble shooting that I noticed but the supports were still hard to take off even though they were organic supports.

Assembling The Hand:

During the assembly I think it went pretty smoothly with a few minor errors we came along the way. For our guide we use a pdf file that e-NABLE provided which we used the most ((https://cdn.thingiverse.com/assets/dd/6b/45/30/fc/Phoenix_v2_assembly_guide.pdf), we mostly relied on the pictures that it showed. The guide did tell us which pin to use but it was hard to know which one was the right pin so we just tried each pin until it matched which hole.

Then there was a step where we had to bend the “thermo gauntlet” which is basically the piece that covers your arm. We had to heat it up and then make it into a curve shape. At first we thought that it was a simple bend but when we went back to put the pins to connect it with the hand shell the holes didn’t match up so we had to reheat it and match it with the holes which took a few tries. Another problem that we faced was tying the string to the fingers. The pictures and the description were very helpful for this step so I thought that we had to use 5 separate strings for each finger. Turns out that we only needed 2 long strings and then another one for the thumb. One long string will control 2 of the fingers. Since I cut them into 4 strands I had to tie them back together. For this step we had to watch a video tutorial to understand what we had to do with the strings.(https://www.youtube.com/watch?v=Der_DD2_zps) Also for this step we had to tie the strings when the gauntlet was raised to 30° which made it harder to tie. But I think that this step should say that the strings should be taught when the gauntlet is straight but not bending the fingers yet. I think this because people might use different strings so to make it taught it will vary by person. In the end we did not put the palm mesh on the gauntlet because we could fit our hand in it so instead we attached a handle so we could grab onto it. This is the case for people who have hands but if the person does not have hands then putting the palm mesh is the way to go but it will need to be heated to give a curved shape.

Designing An Add On For The Hand:

For our second task we had to create a sketch and a design to add onto the hand. My first thought was to add wolverine claws to it. My partner agreed so we went through with this idea and then we drew a basic sketch of what the claw would look like. I sketched the base that would be attached to the hand and I started to build it piece by piece. For the base I added a hole on the bottom so it could be screwed onto the hand. Then on top I add three half circles with 10mm holes so I can make another hinge to connect to it. In total there are three parts of the claw that will be moving. This is only the first variation so I know that there are still more places that need to be improved. Like in the sketch where I drew the claw with tension, I still need to refine that part so it can smoothly extend and retract.

Reflection 4

I also read about “Inclusive Design for Cognition: Cognitive Recruiting” during this project. It shows the importance of designing for cognitive diversity, which includes people with different abilities in areas such as learning, decision-making, focus, recall, and communication. This also can be connected to our project, which aims to create affordable, customizable prosthetic hands for individuals with limb differences. By using an open-source design, e-NABLE gives us access to different prosthetics, ensuring that people who might otherwise be excluded from traditional medical solutions can benefit from these devices. The principles of inclusive design are particularly relevant. For example, the assembly process required careful attention to detail, and while the instructions were helpful, they did not always give us the best explanation of how to assemble the hand. However e-NABLE provided multiple different sources that we could reference which gave us different perspectives of how to assemble the hand. This highlights the importance of designing not just for the end user but also for the makers and assemblers. I think that the open-source nature of the e-NABLE hand is very good. It gives anyone access to prosthetics, allowing anyone with a 3D printer to create a device for themselves or others. This will reduce barriers to access for people who might not be able to afford traditional prosthetics.
